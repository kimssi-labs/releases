# kimssi-labs 배포 창구

kimssi-labs 도구의 설치 파일이 [Releases](../../releases)로 배포됩니다.

| 프로그램 | 종류 | 기능 |
|---|---|---|
| **WMX Switcher** | Windows 설치 파일 (`.exe`) | 한 PC에 설치된 WMX3/WMX2/MXR2 버전을 전환합니다. 버전 간 파일 비교·복사, 관련 레지스트리 값 편집, 버전 폴더 보관(DB)을 지원합니다. |
| **WMX3ENIViewer** | VS Code 확장 (`.vsix`) | WMX3 EtherCAT ENI 파일을 VS Code에서 해석하고 검증합니다. 구문 강조, 호버 디코드, 진단, 요약 뷰를 제공합니다. |
